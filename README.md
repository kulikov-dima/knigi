# Этап 4 — состояние после практики

Запуск: `python app.py`

Проверьте: `/`, `/table`, `/classic`, `/book/1` (внизу «Все поля книги»), `/book/14`

## Что сделано

- 4.1 — сначала был простой список `<ul>`, затем его заменили карточками из 4.5.
- 4.2 — `/table`, чередование строк через `loop.cycle('odd', 'even')`.
- 4.3 — «Всего книг» через `length`.
- 4.4 — метки жанров на странице книги, `for ... else` для пустого списка.
- 4.5 — карточки на главной: вложенный цикл по жанрам.
- 4.6 — первая карточка получает класс `first` (золотая рамка).
- 4.7 — `/classic` с фильтрацией `for ... if`.
- 4.8 — все поля книги через `items()` в раскрывающемся блоке `<details>`.

Ссылок между страницами пока нет: их добавим в этапе 5 через `url_for`.

## Ответы на вопросы

**4.8.** Без особой обработки жанры выводятся как список Python: `genres: ['роман', 'фантастика', 'сатира']`, со скобками и кавычками. Исправление: проверить ключ и для `genres` применить `join`, как сделано в шаблоне.
