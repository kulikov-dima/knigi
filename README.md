# Этап 7 — состояние после практики (итоговое задание)

Запуск: `python app.py`

Пройдите по списку проверки из итогового задания: `/book/13`, `/book/14`, `/book/100`, `/?genre=фантастика` (6 книг), сортировка вместе с фильтром, `/classic`.

## Что сделано

- 7.1 — меню вынесено в `partials/nav.html`, нижняя строка подвала — в `partials/footer.html`. Оба подключаются в `base.html` через `include`.
  Блок `{% block footer %}` остался в `base.html`, а не во фрагменте: блоки переопределяются только через наследование, во вставленном через `include` файле страница книги не смогла бы дополнить подвал через `super()`.
- 7.2 — карточка книги в `partials/book_card.html`, на главной она вставляется в цикле.
- 7.3 — та же карточка на `/classic` (раньше там был простой список).
- 7.5 — в карточке вся логика: рейтинг или «Нет оценки», класс `top`, метки жанров ссылками на фильтр, «Жанр не указан».
  Подсветку первой карточки из задания 4.6 (`loop.first`) мы убрали. Вставленный шаблон надёжно видит переменную цикла `book`, но переменная `loop` внешнего цикла внутри `include` бывает недоступна: Jinja передаёт её только в некоторых случаях, и можно получить ошибку `'loop' is undefined`. Логику, которая зависит от `loop`, лучше оставлять в шаблоне с самим циклом.

## Ответы на вопросы

**7.4.** Если на `/classic` написать `{% for b in books ... %}`, страница упадёт с ошибкой `UndefinedError: 'book' is undefined`. Внутри `book_card.html` используется переменная `book`, а её больше нет — есть только `b`. Само по себе `{{ book.title }}` вывело бы пустоту, но в карточке есть обращения вроде `book.rating >= 4.5` и `url_for('book', book_id=book.id)`, которые с неопределённой переменной не работают. Вывод: имя переменной цикла должно совпадать с тем, что ожидает вставляемый фрагмент.
