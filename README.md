# Этап 5 — состояние после практики

Запуск: `python app.py`

Проверьте: `/`, `/?genre=фантастика` (6 книг), `/?genre=фантастика&sort=year`, `/?genre=поэзия` (пусто), `/table`, `/book/1`

## Что сделано

- 5.1 — все ссылки построены через `url_for`. Если поменять роут на `/books/<int:book_id>`, ссылки обновятся сами.
- 5.2 — названия в карточках, таблице и на `/classic` стали ссылками.
- 5.3 — «← Назад к каталогу» на странице книги.
- 5.4 — CSS подключён через `url_for('static', filename='style.css')`.
- 5.5 — меню с подсветкой через переменную `active`. Пока оно **скопировано в каждый шаблон** — это неудобство исправим в этапе 6.
- 5.6 — метки жанров ведут на `/?genre=...`, функция `index` фильтрует книги по `request.args`.
- 5.7 — строка всех жанров (функция `all_genres` собирает их через `set`), ссылка «все», подсветка выбранного жанра.
- 5.8 — сортировка по году и по названию через `sorted`.
- 5.9 — в каждую ссылку передаются оба параметра, поэтому фильтр и сортировка не сбрасывают друг друга. `None` в адрес не попадает.
- 5.10 — «Найдено книг» и «Книг с таким жанром нет» через `for ... else`.
