# Этап 3 — состояние после практики

Запуск: `python app.py`

Проверьте: `/book/2` (классика, золотой заголовок), `/book/13` (новинка, нет оценки, нет описания), `/book/14` (жанры не указаны), `/book/100` (404)

## Что сделано

- 3.1 — плашки «Классика» / «Новинка» через `if / elif`.
- 3.2 — три варианта толщины книги.
- 3.3 — описание через `is defined`, иначе серый текст.
- 3.4 — жанры через `if book.genres` (пустой список считается ложью).
- 3.5 — класс `top` однострочным условием. Сначала проверяем `is defined`, иначе книга 13 сломается на сравнении. CSS подключён ссылкой вручную, в этапе 5 заменим на `url_for`.
- 3.6 — проверка `in` с `or`.
- 3.7 — `abort(404)` вместо строки.
- Временные строки для исследования из этапа 2 и строка про `~` удалены.
