# Этап 2 — состояние после практики

Запуск: `python app.py`

Проверьте: `/book/1`, `/book/13`, `/book/14`

## Что сделано

- 2.1 — название через `upper`.
- 2.2 — жанры через `join(" · ")` и количество через `length`.
- 2.3 и 2.5 — описание: сначала `default`, потом `truncate(80)`. Порядок важен: если поставить `truncate` первым, он получит пустое значение.
- 2.4 — рейтинг через `default("нет оценки")`.
- 2.6 — `(book.pages / 14) | round(1)`. Скобки обязательны: без них фильтр применится только к числу 14.
- 2.7 — длина названия через `length`.
- 2.8 — две строки для исследования (в этапе 3 их можно удалить).

## Ответы на вопросы

**2.8.** Для книги 14 оба варианта выводят пустоту: `first` у пустого списка ничего не находит, а `join` склеивает пустой список в пустую строку. Там же видно «Жанры:  (0)» — некрасиво. Это исправим условием в этапе 3.
